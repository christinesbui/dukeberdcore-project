# dukeberdcore-project
As a Research Intern with the Duke BERD Methods Core, I collaborated with the Duke Global Health Institute on a project regarding covariate adjustment in cluster randomized trials. 

This repository includes a presentation that was required as part of the internship program (tells you the details of the project and results I've seen as I cleaned and explored the data collected thus far) and the code that explores the data. You can view my code (done in R) through the QMD file or PDF file! 

Enjoy looking through the work I've done!
